# Risks and responses

| Risk | Likelihood / impact | Trigger / mitigation | Owner |
|---|---|---|---|
| Registration missed while building | Medium / critical | Submit by internal 25 Oct target; confirm real cutoff now | Teacher |
| Unknown upload deadline/rules | High / high | Check form/organizer requirements; move freeze earlier if needed | Teacher |
| Model recognizes desk/room instead of sound | High / high | Independent events and contributor/device/room holdout; reject or retrain | Codex |
| Noise and simultaneous groups | High / high | Single live station, mute playback during capture, sample option, honest mode labels | Teacher + Codex |
| Mic permission/device limitations | Medium / high | Actual device POC; no permission trap; denial path | Codex |
| Offline bundle misses model dependencies | Medium / high | Self-contained assets, network-disabled restart test, prepared local backup | Codex |
| Relative signal taught as calibrated loudness | Medium / high | Label relative; no dB/health threshold; teacher review | Teacher |
| Simulations mistaken for live AI measurement | Medium / high | Explicit mode labels and provenance in evidence/report/demo | Codex + teacher |
| DSKP stream/edition mismatch | Medium / high | Current teacher copy before content freeze; revise mappings | Teacher |
| Child privacy / incidental speech | Medium / high | Adult object data, memory-only capture, no raw audio exports or logging | Codex + teacher |
| Model/base asset license incomplete | Medium / high | Bill of materials before distribution; replace unlicensed artifacts | Owner + Codex |
| Scope exceeds available teacher time | High / high | 30–38h estimate, bounded POC, remove optional work before musts | Owner |
| Accessibility blocks audio tasks | Medium / high | Described timelines, visual evidence and teacher oral-entry accommodation | Codex + teacher |
| No pupil pilot available | Medium / medium | Teacher/adult walkthrough; explicitly defer usability/outcome claims | Teacher |
| Prototype looks finished before feasibility known | Medium / medium | POC before product; selected mockups after framing; no fake runtime evidence | Owner + Codex |

Residual risks are reported with release evidence. No guarantee of winning, acceptance, hardware compatibility or learning gains is made by this plan.
