## Failure/recovery script

If venue noise causes uncertainty, say: “AI belum pasti kerana terdapat bunyi lain. Kita semak menggunakan sampel contoh.” Switch to actual inference on a bundled sample; label it as sample input. If inference itself fails, show labelled prerecorded demonstration and state the limitation. Preserve a genuine failure in the explanatory story rather than presenting a fixed result as live AI.

Backup kit: verified laptop/charger/mouse, permitted object sounds, headphones for preview, cached verified app, prepared localhost backup, approved labelled recording and printed report/abstract. Test offline after browser restart and at the intended display resolution. A printed poster or video can explain the product but does not substitute for a passed AI gate.

## Evidence integrity

Use only actual model metrics and dated pilot observations. Include sample sizes, device/environment and whether inputs were live or prerecorded. If no pupil pilot is permitted, say “teacher-reviewed prototype; pupil validation pending.” Only use pupil photos or work with school/guardian permissions as applicable; anonymized aggregate evidence is preferred. Do not commit registration acknowledgements containing personal details into this repository.
