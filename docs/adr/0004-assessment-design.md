# ADR 0004 — Evidence-first assessment and task-specific workspaces

Date: 24 October 2026. Status: PROPOSED; teacher review and visual selection pending.

Context: classification success is not proof of science learning; a generic quiz layout does not fit recording, spatial reasoning, A/B comparison and planning equally well.

Decision: retain a consistent shell with four distinct interaction workspaces. Save original predictions, observations, explanations, hints and revisions. Teacher reviews formative reasoning; no automatic official TP. Provide equivalent keyboard and non-listening routes.

Alternatives: reward AI accuracy or badges as mastery (invalid inference); identical cards for every mission (reduces task clarity); full classroom analytics (unnecessary MVP scope).

Consequences: more state design than a simple quiz, offset by reusable evidence engine. Teacher review and content signoff are release dependencies. Product Design mockups/selection remain required before UI implementation; this prose is not visual approval.
